Параметры анализа

Координаты по умолчанию — пример региона Беэр-Шевы, не конкретного поля. Период — прошедшие даты, максимум 366 дней.

Почва (по желанию)

Эти поля не запрашиваются у NASA. Заполняй их только при наличии собственных данных о почве.

Ограничения и предупреждения

    Источники: NASA POWER Daily API. Это локальный инструмент команды OrbitFarm, а не официальный инструмент NASA. Для публичного сайта на Vercel нужна отдельная серверная интеграция. Данные за прошлые дни не являются прогнозом урожая.
